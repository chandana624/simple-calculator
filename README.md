# Simple Calculator

A console-based calculator built in Python that performs addition, subtraction, multiplication, and division.

## Features
- Takes two numbers and an operator as input
- Handles division by zero with a proper error message
- Handles invalid input (e.g., letters instead of numbers) without crashing
- Lets the user calculate multiple times in one session

## Technologies
- Python

## Concepts Used
- Functions
- Loops
- Conditional statements (if-elif-else)
- Error handling (try-except)
